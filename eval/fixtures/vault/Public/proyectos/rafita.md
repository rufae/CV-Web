# Rafita

Asistente personal con RAG sobre el Segundo Cerebro (bóveda Obsidian). Usa
embeddings bge-m3 servidos por Ollama, Chroma como base vectorial y modelos
locales para generación. Todo el tráfico entre nodos viaja por Tailscale y el
vault privado nunca se expone.
