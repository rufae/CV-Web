# CV Web

Portfolio personal con chatbot IA. El frontend es una SPA en React,
TypeScript, Vite y Tailwind CSS; el backend es una API FastAPI que sirve el
frontend compilado y el chat con RAG sobre una colección pública del Segundo
Cerebro. Se despliega de forma autoalojada en un nodo HP.
