# TFM: proyecto padre de Rafita

El Trabajo de Fin de Máster (TFM) de Rafael fue el **proyecto padre de
Rafita**: un proyecto de asistente personal con funcionalidades de chatbot.

**Rafita** es su versión evolucionada: añade audios, reuniones, más
herramientas, IA local y respuestas y privacidad mejoradas gracias al segundo
cerebro (bóveda Obsidian).

## Preguntas frecuentes

- **¿Qué fue tu TFM?** El TFM fue el proyecto padre de Rafita, un asistente
  personal con funciones de chatbot.
- **¿Qué proyecto fin de máster hiciste?** El proyecto padre de Rafita, que
  después evolucionó a la versión actual con audios, reuniones y más
  herramientas.
- **¿Qué hiciste en el TFM?** Se construyó un asistente personal tipo chatbot
  sobre el que después se desarrolló Rafita.
